# Python Basics

## Short Description

This repository contains basic Python programs created for learning and practicing fundamental Python programming concepts. It includes programs based on dictionaries, factorial, Fibonacci series, multiplication tables, patterns, and lists.

## Programs Included

- **Dictionary.py** – Demonstrates basic dictionary operations in Python.
- **Factorial.py** – Calculates the factorial of a number.
- **Fibonacci.py** – Generates the Fibonacci series.
- **Multiplication.py** – Prints the multiplication table of a number.
- **Pattern.py** – Prints basic patterns using loops.
- **list.py** – Demonstrates basic list operations in Python.
